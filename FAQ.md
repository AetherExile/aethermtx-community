# Frequently asked questions

## Is AetherMTX Community Edition free?

Yes. Community Edition is free to download and use. There is no account, payment, license key, expiry or Discord membership requirement.

## Is it open source?

No. It is free but closed source. This repository is the official binary distribution and documentation repository, not a source repository.

## Which Path of Exile 2 installation is supported?

The standalone Grinding Gear Games Windows client and Steam are supported. Select the installation you actually use; the application detects the correct data layout automatically.

## Does it work while the game is running?

No. Close Path of Exile 2 and its launcher before using Apply or Restore Original.

## What does it include?

Community Edition includes 52 Official Looks, 43 complete armour cores and 279 optional Back Attachments. Apply and Restore are unlimited.

## Why is the EXE unsigned?

The current Community Edition release is intentionally unsigned. Windows or antivirus software may show a reputation warning. Verify the SHA-256 against the value in the exact GitHub Release before running it.

Do not disable your security software globally. If a scanner reports the file, confirm that you downloaded the exact release asset and compare its checksum before deciding what to do.

## Is it safe or ban-proof?

No such claim is made. This is an independent third-party tool that changes game data. Its use may violate Grinding Gear Games' Terms of Use and may result in account action. Use it entirely at your own risk.

## What does Restore Original do?

Restore Original removes the currently applied Community Edition look and returns the supported installation to its original appearance. Let the operation finish before launching the game.

## What happens after a game update?

Do not assume an older release supports a new game build. Check the latest release notes. Unsupported game-file states fail closed and require a compatible Community Edition release.

## Is Discord required for support?

No. The [Aether Exile Discord](https://discord.gg/KNd66FXtvw) is the main community hub for builds, patch-status updates, showcases and help, but GitHub Issues and direct Releases remain available without joining.

## Can I redistribute the EXE?

Link to the official GitHub Release whenever possible. This keeps the filename, checksum, release notes and risk disclosure together. Never modify the binary or present a mirror as an official Aether Exile release.
