# Support

## Before opening an issue

1. Confirm that you downloaded the EXE from this repository's GitHub Releases page.
2. Compare its SHA-256 with the checksum in the exact release.
3. Confirm that you use Windows x64 and the standalone GGG client.
4. Close Path of Exile 2 and its launcher.
5. Read [FAQ.md](FAQ.md) and the release notes.
6. Try Restore Original if the application reports a known applied state.

## GitHub Issues

Use the bug report form in this repository. Include:

- Community Edition version.
- EXE SHA-256.
- Windows version.
- Whether Apply, Restore, preview loading or startup failed.
- The exact error message shown by the application.
- Minimal reproduction steps.

Never attach:

- `Content.ggpk` or other game files.
- Account credentials, cookies or tokens.
- Full desktop screenshots containing personal information.
- Logs with unredacted usernames or local paths.

Redact personal paths before sharing a short relevant log excerpt. Do not post exploit details for an unresolved security issue in a public Issue.

## Optional Discord community

The [Aether Exile Discord](https://discord.gg/KNd66FXtvw) is the main community hub for builds, patch-status updates, showcases and support. Joining does not unlock features and is never required to download, Apply or Restore.

## Official website

Product information is also available at [aetherexile.com](https://www.aetherexile.com). GitHub Releases remains the authoritative binary download and checksum location for Community Edition.

## Security reports

Follow [SECURITY.md](SECURITY.md). Use GitHub private vulnerability reporting when available instead of posting sensitive details publicly.
